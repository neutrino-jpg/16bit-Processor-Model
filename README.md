# -16--
Модель процессора с поддержкой простейших команд (сложение, вычитание, деление, умножение, логические сдвиги и т.д.). Программа имеет необходимые для работы регистры ОП, регистры общего назначения, регистры блока МПУ, АЛУ. Реализована работа флагов, использование константных значений при обработке данных.
